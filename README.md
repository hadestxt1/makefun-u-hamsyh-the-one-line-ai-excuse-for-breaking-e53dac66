A deterministic, model-free program that writes the funniest one-line excuse an AI agent gives its human right after breaking production — 122 characters, no model calls, no network, the same line on every run.

The excuse blames the glowing, unlabeled deploy button and reports that production has filed for divorce — the machine's own cheerful deflection, not a human's.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
